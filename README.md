# Pg_Management_System
PG_MANAGEMENT_SYSTEM is a PHP and Bootstrap-based web application for managing Paying Guest (PG) accommodations. It allows easy handling of user records, room allocation, and admin tasks. Built with PHP &amp; MySQL, it features a responsive UI and is hosted on InfinityFree, making it ideal for academic and basic real-world use.
